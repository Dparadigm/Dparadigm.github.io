Moving our websites to an AI-ready platform

We are moving our five websites off WordPress to a faster, modern setup built by Aero Interactive. Each site moves over as it looks today, and redesigns come after. We start with the book site, headsortailsiwin.com, this month.

    A few words, in plain English

    CMS
    Content management system. The place where we write and edit website content.
    Sanity
    The CMS we are moving to.
    Cloudflare Pages
    The service that hosts our sites and serves them to visitors.
    Rebuild
    Regenerating the site so new content shows up. Ours happens nightly, only if something changed.
    Redirect (301)
    A permanent forward from an old web address to a new one, so links and search rankings keep working.
    Agent
    An AI assistant that does a specific job, like our Trinity Copywriter.
    MCP
    A standard way for AI agents to connect to tools like Sanity.
    Draft / Publish
    A draft is saved but not live. Publishing approves it to go on the site.
